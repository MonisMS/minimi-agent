# 60-second demo checklist

Use fictional records only. Keep the browser visible and show no credentials or real customer history.

1. **0–10 seconds:** Open the explicitly isolated demo and show the original dated recommendation.
2. **10–25 seconds:** Ask a dated follow-up and show the saved original exchange that answers it.
3. **25–42 seconds:** Start a recheck. Show one supported change, one incompatible commitment, and at least one unresolved row without implying missing evidence means unchanged.
4. **42–55 seconds:** Open a retained evidence excerpt and show its capture/effective-date details separately from the current source link.
5. **55–60 seconds:** End on the unresolved coverage count and state that the walkthrough uses scripted providers.

Current limitation: the browser smoke test proves the demo namespace path and basic chat workflow.
